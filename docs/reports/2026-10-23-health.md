**Worth your attention, roughly in order:**

1. **Pillow 12.3.0** in `tools/requirements.txt` - 39 advisories, worst 9.8
   (critical); fixed in 13.0.0. Build-time only (the art and audio tools), but
   it parses images.
2. **Vite 8.3.1** - 6 advisories, worst 7.5; fixed in 8.3.3, a patch bump. Dev
   server only.
3. **`sim.ts` (567 code lines) and `Play.ts` (553)** over the 400 limit. The
   `architecture` skill uses both as its worked examples: `Play.ts` splits into
   sounds, effects, results and a shared camera system; `sim.ts` into spawning,
   destruction, contacts, hazards and steering. `daily-table.ts` (1,191) is
   generated and correctly not counted.
4. **Unused code** - `zzfx` is an unused dependency; four scripts
   (`daily-table`, `damage-sheet`, `level-report`, `sheet-mirror`) are not
   reachable from any entry, which may be fine for one-off scripts run by hand;
   27 exports are unused, mostly tuning constants in `sim/` and `vehicles.ts`.
5. **Semgrep (6)** - a `child_process` call built from a test argument
   (`e2e/build-modes.spec.ts`), an SVG string assembled from data
   (`scripts/checks/sheets.ts`), a `RegExp` built from a map's keys
   (`src/art/paint.ts`), and dynamic `urllib` calls in three `tools/` scripts.
   All take inputs the project controls; none looks exploitable, but the
   `RegExp` should escape its keys.
6. **pyright (4)** - a dict typed narrower than what is passed in `art.py:50`,
   a possible `None` iteration at `art.py:87`, and two test typing issues
   (`Image.LANCZOS` moved to `Image.Resampling.LANCZOS` in recent Pillow).
7. **Lint (449)** - 276 are `no-explicit-any`, mostly in the e2e specs; 31
   functions over SonarJS's cognitive-complexity threshold; 29 fixed waits in
   tests (`waitForTimeout`).
8. **ruff (346)** - 185 long lines; 36 `assert` in tests (expected); the rest
   is style. Security rules: 5 subprocess calls with partial paths, 4
   `urlopen` calls - the same as Semgrep's.

**False positive:** all six "secrets" are the string `junkrally.save.v1`, the
localStorage key, in `save.ts` and five save tests. gitleaks' generic-API-key
rule flags it on entropy. To silence it, list the six fingerprints in a
`.gitleaksignore` - not done, per your instruction.

**Worth your attention, roughly in order:**

1. **Dependencies are about two years behind** - 127 advisories, 6 critical.
   The heaviest: `axios` 1.6.2 (31 advisories, worst 8.7), `protobufjs` 7.2.5
   (11, worst 9.8), `node-forge` 1.3.1 (7), `brace-expansion` (8), and
   `form-data`, `crypto-js`, `proxy-addr`, `sha.js` at 9.1-9.4. Many are
   transitive (through Apollo, gRPC, the AWS SDK and webpack). `express`
   4.18.2 has fixes on the 4.x line, so the "fixed in 5.0.0-beta.3" figure is
   only the highest version named, not the one to move to.
2. **Container hardening (Semgrep)** - the `Dockerfile` runs as root (no
   `USER`), and the `db` service in `docker-compose.yaml` allows privilege
   escalation and has a writable root filesystem.
3. **Lint (132)** - 54 `no-explicit-any` (39 in `src/types/stripe/subscription.ts`
   alone), 28 unused variables and 14 unused imports, 14 TODO tags, 3 swallowed
   exceptions.
4. **Run it again after `npm install`** to get the type check and unused-code
   results.

## What the run taught the tool

Fixed before this report, so the numbers above are from the corrected runner:

- Lint and sizes now read only what git tracks: the first run counted 16,000
  findings in Junk Rally's built `dist-poki/` and `dist-crazygames/` bundles.
- ruff prints counts per rule rather than every diagnostic.
- Semgrep and jscpd report READ when they find something (both exit 0 by
  default, which showed as PASS).
- gitleaks prints file, line and commit for each finding, values redacted.
- OSV prints one line per package instead of one per advisory.
